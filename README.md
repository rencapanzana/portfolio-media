# portfolio-media

Images and videos for rencapanzana.netlify.app (marketing) and rencapanzana-operations.netlify.app (ops), served through jsDelivr because Netlify is slow to load large files from the Philippines.

Source of truth is the sites themselves (ren-portfolio/img, ren-portfolio/case-studies, ren-portfolio/operations/img). After changing a file there, copy it here, commit, push, and update the commit hash in the pages' CDN constant.

URL pattern: https://cdn.jsdelivr.net/gh/rencapanzana/portfolio-media@<commit>/<path>
